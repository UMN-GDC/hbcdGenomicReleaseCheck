# Exclusion Validation

## Overview

The pipeline implements a **three-layer exclusion system** to ensure no excluded subject appears in release outputs. Validation occurs at multiple stages with final verification in Step 30 and the test suite.

## Exclusion Sources

### 1. HBCDexclusions.csv (PSCID-level)

**Location**: `$HBCD_DATA_DIR/HBCDexclusions.csv`

**Format**: CSV with exclusion reasons as columns, pscids as values

```csv
withdrawal,consent_issue,data_quality,other
12345,,
,67890,
,,11111,
,22222,
```

**Processing**:
```python
# Load all columns, combine into single exclusion set
excluded_pscids = set()
for col in df.columns:
    vals = df[col].dropna().astype(str).str.strip()
    excluded_pscids.update(vals[vals != "nan"])

# Map to release_candid via identifiers crosswalk
exc_rc = identifiers[identifiers.pscid.isin(excluded_pscids)].release_candid
```

**Validation**: Step 30 per-column check + `test_exclusions.py` tests

### 2. Excel QC Exclusion List (release_candid-level)

**Location**: `$HBCD_DATA_DIR/HBCD_genetics_QC1_missing_race_LORIS.xlsx` (sheet: `Exclude_Summary`)

**Format**: `Sampled ID` column = `prefix_{release_candid}_{pscid}`, `Study_ID` column for relationship

```excel
| Sampled ID      | Study_ID    | ... |
|-----------------|-------------|-----|
| SUBJ_1234567890_12345 | 12345C | ... |
| SUBJ_2345678901_23456 | 23456M | ... |
```

**Processing**:
```python
exc = pd.read_excel(path, sheet_name="Exclude_Summary")
exc[["_", "release_candid", "_pscid"]] = exc["Sampled ID"].str.split("_", n=2, expand=True)
exc["release_candid"] = pd.to_numeric(exc["release_candid"])
exc["relationship"] = exc["Study_ID"].str[-1]  # C or M
exc_rc = set(exc.dropna(subset=["release_candid"])["release_candid"].unique())
```

**Validation**: Step 30 + `test_exclusions.py::test_excel_excluded_release_candids_absent`

### 3. Pipeline Exclusion List (IID-level)

**Location**: `$RELEASE_DIR/GDA/removed_individuals.txt` (generated by Step 25)

**Format**: Space-separated IIDs (`{release_candid}{C|M}`)

```text
1234567890C
2345678901M
```

**Source**: Excel exclusions mapped via identifiers + relationship

**Validation**: Step 30 + `test_exclusions.py::test_removed_individuals_absent`

## Exclusion Logic Flow

```mermaid
graph TD
    A[HBCDexclusions.csv] --> B[Map pscid → release_candid]
    C[Excel Exclude_Summary] --> D[Extract release_candid directly]
    B --> E[Combined excluded release_candids]
    D --> E
    E --> F[Build excluded IIDs: {rc}C + {rc}M]
    F --> G[Step 25: Filter genotypes]
    F --> H[Step 27: Filter VCFs]
    F --> I[Step 29: Filter derivatives]
    F --> J[Step 30: Validate]
    G --> K[keep_list.txt = par_visit ∩ identifiers - E]
    K --> L[All downstream filtering uses keep_list]
```

## Step 25: Filter Application

```python
# par_visit candids (completed visits only)
par_candids = load_par_visit_candids()

# Excluded release_candids (Excel)
exc_rc = load_excluded_release_candids()

# Valid = par_visit ∩ identifiers - excluded
valid_rc = (
    set(identifiers[identifiers.release_candid.isin(par_candids)].release_candid)
    - exc_rc
)

# Also apply HBCDexclusions.csv at identifier level
identifiers = identifiers[~identifiers.pscid.isin(excluded_pscids)]
```

## Step 30: Validation Checks

### 1. GDA/merged_chroms.fam
```python
# FID-level (release_candid)
fam_rc = set(fam[fam.FID != 0].FID.unique())
overlap_rc = exc_rc ∩ fam_rc

# IID-level
fam_iids = set(fam.IID.astype(str))
exc_iids = {f"{rc}C" for rc in exc_rc} ∪ {f"{rc}M" for rc in exc_rc}
overlap_iid = exc_iids ∩ fam_iids
```

### 2. HBCDexclusions.csv Per-Column
```python
for col in HBCDexclusions.columns:
    col_pscids = set(df[col].dropna())
    col_rc = identifiers[identifiers.pscid.isin(col_pscids)].release_candid
    overlap = col_rc ∩ fam_rc
```

### 3. Derivative Files (IID-level)
```python
check_file("genesis/pcrelate_relatedness.grm.id", ["1"], reader="fwf")
check_file("genesis/pcair_weights.tsv", ["subject_id"], reader="tsv")
check_file("genesis/pcrelate_relatedness.tsv", ["ID1", "ID2"], reader="tsv")
check_file("genesis/pcrelate_relatedness.grm.gz", via .id mapping)
check_file("cnv/CNV_slim.txt", ["sample_id"], reader="tsv")
check_file("cnv/CNV_bookmarks.csv", ["sample_id"], reader="csv")
```

### 4. Cross-Check: Unexpected IIDs
```python
# IIDs in output that are NEITHER in release set NOR excluded
extra = all_ids - release_iids - exc_iids
if extra:
    print(f"WARN: {len(extra)} unexpected IIDs: {sorted(extra)[:10]}")
```

## Re-running After Exclusion Changes

If exclusion lists change, only Phase C needs re-run:

```bash
# 1. Update exclusion files in $HBCD_DATA_DIR
# 2. Re-run Phase C (steps 25-30)
python 25-filterGenotypeFiles.py      # Rebuilds keep_list with new exclusions
./26-run_plink_filter.sh              # Re-filters PLINK
sbatch 27-filter_imputed_vcf.SLURM    # Re-filters VCFs
python 28-cnv-deid.py                 # Re-de-IDs CNV (source always pscid)
python 29-filter_release_outputs.py   # Re-filters all derivatives
python 30-validateExclusions.py       # Validates new exclusions
python -m pytest tests/ -v            # Full test suite
```

## Common Issues

| Issue | Cause | Resolution |
|-------|-------|------------|
| Overlap in Step 30 | Exclusion list not applied | Re-run step 25 with updated exclusions |
| Per-column fail | New column in HBCDexclusions.csv | Step 25 handles all columns automatically |
| Unexpected IIDs in derivatives | Stale handoff files | Ensure Phase B de-ID re-run, then step 29 |
| CNV exclusion fail | CNV source not re-de-IDed | Step 28 must re-run (reads pscid source) |
