Subject: HBCD Genomics Release Data Handoff — br_21p3

Hi team,

The HBCD genomics release dataset (br_21p3) is ready for delivery. Here's the data flow:

Source data (de-identified, all QC-passing subjects):
/projects/standard/basu_hbcd/shared/data/

This directory contains the de-identified PLINK dataset onlyQc.{bed,bim,fam}
with release_candid IDs (format {10-digit_candid}{C|M}), along with the
identifiers crosswalk (release_identifiers_20260628.csv), batch info, and
exclusion lists.

Handoff derivatives (GRM, PC-AiR, PC-Relate, CNV) are in:
/projects/standard/basu_hbcd/shared/data_handoff/ — also de-identified.

Output data (release subject subset):
/projects/standard/basu_hbcd/shared/HBCD_genomics_release_br_21p3/genotype_microarray/

Contains the filtered release files:
  GDA/merged_chroms.{bed,bim,fam}        — release PLINK files
  GDA/batch.info                         — visit/plate metadata
  GDA/removed_individuals.txt            — excluded subjects
  genesis/pcair_weights.tsv              — ancestry-adjusted PCs
  genesis/pcrelate_relatedness.grm.*     — PC-Relate GRM (binary + text)
  genesis/pcrelate_relatedness.tsv       — pairwise relatedness
  cnv/CNV_slim_clean.txt                 — CNV calls
  imputed/                               — per-chromosome dose VCFs

Filtering pipeline (Phase C scripts):
The following scripts reproduce the output from the source data. Run in order:

  export HBCD_RELEASE=br_21p3
  source ~/miniconda3/etc/profile.d/conda.sh
  conda activate python

  # 1. Build subject whitelist + de-ID mapping
  python 25-filterGenotypeFiles.py

  # 2. PLINK2 --keep → GDA/merged_chroms
  ./26-run_plink_filter.sh

  # 3. Filter imputed VCFs (SLURM array, 24 tasks)
  sbatch 27-filter_imputed_vcf.SLURM

  # 4. De-identify CNV (pscid → release_candid)
  python 28-cnv-deid.py

  # 5. Filter all derivatives (GRM, PCs, pairwise, CNV) to release IIDs
  python 29-filter_release_outputs.py

  # 6. Validate no excluded subjects leaked into outputs
  python 30-validateExclusions.py
  python -m pytest tests/ -v

The release tag is controlled by HBCD_RELEASE (default br_21p3). To produce a
different release, set: export HBCD_RELEASE=br_22p0

Key design decisions:
- De-identification happens first (pscid → release_candid), then filtering —
  so a 3rd party can safely handle only de-identified data.
- Original files are never modified; all output goes to the release-specific
  directory.
- Only subjects with completed par_visit data, passing QC, and absent from
  all exclusion lists are included.

If the exclusion list changes, only Phase C needs re-running — the underlying
derivatives remain valid.
